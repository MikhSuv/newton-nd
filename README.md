# Многомерный метод Ньютона

## Вызов функции

В `main.f90` вызывается подпрограмма `newton`.
Для вычисления вектора результата есть отдельная функция `newton_solve`.

Она принимает следующие аргументы:
  1. Функция с интерфейсом
    ```fortran
    abstract interface
      function vector_func(x) result(y)
          import :: dp
          real(dp), intent(in) :: x(:)
          real(dp) :: y(size(x))
      end function vector_func
    end interface
    ```

  2. Вектор начальных приближений
  3. Максимально возможное количество итераций
  4. Название файла для записи результата (значение по умолчанию `result.dat`)

## Сборка

Команда `make` создает исполнимый файл: `newton-nd`. 
После запуска на экран выводится модуль вектора невязки, в файл `result.dat` записывается результат.

Команда `make test` создает исполнимые файлы, которые тестируют функцию вычисления матрицы частный производных и решения системы нелинейных уравнений методом Ньютона.

## Особенности реализации

Для решение СЛАУ используется метода Гаусса с выбором ведущего элемента. 
Для систем большой размерности можно использовать итеративные методы решения СЛАУ.
